## 🏠 if 语句——如果...就...

### 最基本语法

```python
if 条件:
    做的事
```

**注意：if后面的条件成立，才会执行里面的代码。**

```python
年龄 = 18

if 年龄 >= 18:
    print("你已经是成年人了！")
    print("可以投票了！")
```

**输出：**
```
你已经是成年人了！
可以投票了！
```

### 重要：缩进！

Python里，**缩进就是代码的"等级"**：

```python
# ✅ 正确：有缩进
if True:
    print("我会执行")

# ❌ 错误：没有缩进会报错
if True:
print("我会报错")
```

> 麦叔说：**"Tab键（或4个空格）就是Python的楼梯，按下去代码才属于这个if！"**

---

## ⚖️ else 语句——否则...

```python
if 条件:
    条件成立时做的事
else:
    条件不成立时做的事
```

```python
年龄 = 15

if 年龄 >= 18:
    print("成年人")
else:
    print("未成年")
```

**输出：** `未成年`

---

## 🔄 elif —— 否则如果...

如果有多种情况，用 `elif`：

```python
分数 = 78

if 分数 >= 90:
    print("优秀")
elif 分数 >= 80:
    print("良好")
elif 分数 >= 60:
    print("及格")
else:
    print("不及格，需要加油！")
```

**输出：** `及格`

## 🔢 完整例子：成绩评级系统

```python
print("=== 麦叔成绩评级系统 ===")
分数 = int(input("请输入你的分数："))

if 分数 < 0 or 分数 > 100:
    print("分数无效！请输入0-100之间的数字")
elif 分数 >= 90:
    print("成绩：优秀 🌟")
    print("评语：太棒了！继续保持！")
elif 分数 >= 80:
    print("成绩：良好 👍")
    print("评语：很不错，再接再厉！")
elif 分数 >= 60:
    print("成绩：及格 👌")
    print("评语：刚刚好，别松懈！")
else:
    print("成绩：不及格 💪")
    print("评语：没关系，我们来帮你！")

print("=== 评测结束 ===")
```

## 🔁 嵌套判断——判断里的判断

```python
年龄 = 25
有票 = True

if 年龄 >= 18:
    print("年龄符合要求")
    if 有票:
        print("可以入场！")
    else:
        print("需要买票")
else:
    print("年龄不符合，不能入场")
```

---

## 💡 简洁写法：三目运算符

如果 if/else 很简单，可以写成一行：

```python
# 正常写法
if 年龄 >= 18:
    结果 = "成年人"
else:
    结果 = "未成年人"

# 简洁写法
结果 = "成年人" if 年龄 >= 18 else "未成年人"
```

## ❌ 常见错误

### 错误1：忘了冒号

```python
# ❌ 错误
if 年龄 >= 18
    print("成年")

# ✅ 正确
if 年龄 >= 18:
    print("成年")
```

### 错误2：elif 写成 else if

```python
# ❌ 错误
if 分数 >= 90:
    print("优秀")
else if 分数 >= 80:  # 错了！
    print("良好")

# ✅ 正确
if 分数 >= 90:
    print("优秀")
elif 分数 >= 80:     # 用 elif
    print("良好")
```

✅ if/else 可以嵌套使用
