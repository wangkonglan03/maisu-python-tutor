## 🧮 基础运算

Python做数学题又快又准：

```python
a = 10
b = 3

print(a + b)   # 加法：13
print(a - b)   # 减法：7
print(a * b)   # 乘法：30
print(a / b)   # 除法：3.3333333333333335
```

### 麦叔口诀

```
➕ 加：a + b
➖ 减：a - b
✖️ 乘：a * b
➗ 除：a / b
```

## 🔢 整数除法和取余

### 整数除法 `//`

```python
print(10 // 3)  # 结果：3（只取整数部分）
```

### 取余（取余数） `%`

```python
print(10 % 3)   # 结果：1（10除以3等于3余1）
```

有什么用？

```python
# 判断奇数偶数
数字 = 7
if 数字 % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

### 幂（次方） `**`

```python
print(2 ** 3)   # 2的3次方 = 8
print(5 ** 2)   # 5的平方 = 25
print(10 ** 6)  # 10的6次方 = 1000000
```

## 📊 整数 vs 浮点数

| 类型 | 说明 | 例子 |
|------|------|------|
| 整数 (int) | 整数 | 1, 100, -5, 0 |
| 浮点数 (float) | 小数 | 1.5, 3.14, -0.5 |

**重要发现：**

```python
print(10 / 3)   # 3.3333333333333335（永远是浮点数）
print(10 // 3)  # 3（整数除法，结果是整数）
print(10 * 3.0) # 30.0（任何数乘以浮点数，结果是浮点数）
```

---

## 🧠 运算顺序

和数学一样，Python有运算顺序：

```python
#  先算乘除，后算加减
print(2 + 3 * 4)    # 14（先算3*4=12，再算2+12=14）

# 用括号改变顺序
print((2 + 3) * 4)  # 20（先算2+3=5，再算5*4=20）
```

> 麦叔建议：**有疑问就用括号，括号不会错！**

## 🔧 实用的数学函数

### 绝对值 `abs()`

```python
print(abs(-10))   # 10
print(abs(5))     # 5
```

### 取整

```python
import math

print(math.floor(3.9))   # 向下取整：3
print(math.ceil(3.1))   # 向上取整：4
print(round(3.5))       # 四舍五入：4
print(round(3.4))       # 四舍五入：3
```

### 最大最小

```python
print(max(1, 5, 3))    # 5
print(min(1, 5, 3))    # 1
```

### 常用常数

```python
import math

print(math.pi)   # 3.141592653589793
print(math.e)    # 2.718281828459045
```

## 💱 一个简单计算器程序

```python
# 我的第一个计算器

print("=== 麦叔计算器 ===")

a = 100
b = 35

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} × {b} = {a * b}")
print(f"{a} ÷ {b} = {a / b:.2f}")  # .2f 表示保留2位小数
```

**输出：**
```
=== 麦叔计算器 ===
100 + 35 = 135
100 - 35 = 65
100 × 35 = 3500
100 ÷ 35 = 3.33
```
