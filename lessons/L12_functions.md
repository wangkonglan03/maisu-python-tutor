## 📝 函数的定义

```python
def 函数名():
    函数要做的内容
```

```python
# 定义一个打招呼的函数
def say_hello():
    print("你好！")
    print("欢迎来到Python的世界！")

# 调用函数
say_hello()
```

**输出：**
```
你好！
欢迎来到Python的世界！
```

## 📌 带参数的函数

参数 = 给函数传入数据

```python
def greet(名字):
    print(f"你好，{名字}！")
    print(f"{名字}，今天过得怎么样？")

greet("小明")    # 你好，小明！
greet("小红")    # 你好，小红！
```

---

## 🔢 多个参数

```python
def add(数字1, 数字2):
    结果 = 数字1 + 数字2
    print(f"{数字1} + {数字2} = {结果}")

add(10, 20)   # 10 + 20 = 30
add(5, 3)     # 5 + 3 = 8
```

---

## 🔄 返回值 return

有时候函数需要"返回一个结果"：

```python
def add(数字1, 数字2):
    结果 = 数字1 + 数字2
    return 结果  # 返回结果

# 调用函数并使用返回值
总和 = add(10, 20)
print(总和)  # 30

# 也可以直接用
print(add(5, 3))  # 8
```

> 麦叔说：**"return就是函数的'出口'，告诉调用者'这是你要的结果'。"**

---

## 🔙 多返回值

```python
def 计算(数字1, 数字2):
    和 = 数字1 + 数字2
    差 = 数字1 - 数字2
    return 和, 差  # 返回多个值（实际上返回元组）

结果 = 计算(10, 5)
print(结果)  # (15, 5)

# 也可以拆开接收
和, 差 = 计算(10, 5)
print(和)  # 15
print(差)  # 5
```

    else:

### 例2：计算BMI

```python
def calc_bmi(体重, 身高):
    bmi = 体重 / (身高 ** 2)
    if bmi < 18.5:
        分类 = "偏瘦"
    elif bmi < 24:
        分类 = "正常"
    elif bmi < 28:
        分类 = "偏胖"
    else:
        分类 = "肥胖"
    return round(bmi, 1), 分类

bmi, 分类 = calc_bmi(65, 1.75)
print(f"BMI={bmi}，属于{分类}")
```

### 练习2：计算器函数
定义函数计算加减乘除

```python
def calc(数字1, 数字2, 运算符):
    if 运算符 == "+":
        return 数字1 + 数字2
    elif 运算符 == "-":
        return 数字1 - 数字2
    elif 运算符 == "*":
        return 数字1 * 数字2
    elif 运算符 == "/":
        if 数字2 != 0:
            return 数字1 / 数字2
        else:
            return "除数不能为0"
    else:
        return "不支持的运算符"

print(calc(10, 5, "+"))  # 15
print(calc(10, 0, "/"))  # 除数不能为0
```

### 练习3：温度转换
华氏度转摄氏度：°C = (°F - 32) × 5/9

```python
def f_to_c(华氏度):
    摄氏度 = (华氏度 - 32) * 5 / 9
    return round(摄氏度, 1)

print(f_to_c(100))  # 37.8
```
