## 🔄 生活比喻：重复动作

想象你要打印10次"你好"：

**不用循环：**
```python
print("你好")
print("你好")
print("你好")
print("你好")
print("你好")
print("你好")
print("你好")
print("你好")
print("你好")
print("你好")
```

**用循环：**
```python
for i in range(10):
    print("你好")
```

> 麦叔说：**"循环就是让程序'偷懒'的工具，重复的事交给它！"

## 🏠 for 循环的基本语法

```python
for 变量 in 序列:
    重复做的事
```

```python
for i in range(5):
    print("第", i, "次")
```

**输出：**
```
第 0 次
第 1 次
第 2 次
第 3 次
第 4 次
```

## 🔢 range() 函数

`range()` 就像数数：

```python
range(5)      # 0, 1, 2, 3, 4（从0开始，不包括5）
range(1, 5)   # 1, 2, 3, 4（从1开始，不包括5）
range(0, 10, 2)  # 0, 2, 4, 6, 8（步长为2）
range(5, 0, -1)  # 5, 4, 3, 2, 1（倒着数）
```

### 语法：`range(开始, 结束, 步长)`

```python
# 打印1到10
for i in range(1, 11):
    print(i)
```

## 📝 循环的经典用法

### 1. 计数循环

```python
# 打印1-100的整数
for i in range(1, 101):
    print(i)
```

### 2. 求和

```python
# 计算1+2+3+...+100
总和 = 0
for i in range(1, 101):
    总和 = 总和 + i
print("1+2+3+...+100 =", 总和)
```

### 3. 遍历字符串

```python
# 打印每个字符
名字 = "Python"
for 字符 in 名字:
    print(字符)
```

**输出：**
```
P
y
t
h
o
n
```

### 4. 遍历列表

```python
# 打印购物清单
清单 = ["苹果", "香蕉", "牛奶", "面包"]
for 物品 in 清单:
    print("- " + 物品)
```

## 🔢 嵌套循环——循环里的循环

```python
# 打印乘法表
for i in range(1, 4):      # 外层循环：1, 2, 3
    for j in range(1, 4):  # 内层循环：1, 2, 3
        print(f"{i} × {j} = {i*j}")
    print("---")  # 每行结束后打印分隔线
```

**输出：**
```
1 × 1 = 1
1 × 2 = 2
1 × 3 = 3
---
2 × 1 = 2
2 × 2 = 4
2 × 3 = 6
---
3 × 1 = 3
3 × 2 = 6
3 × 3 = 9
---
```

## ⛔ break —— 提前退出循环

```python
# 找到第一个能被3整除的数
for i in range(1, 20):
    if i % 3 == 0:
        print("找到了，第一个是", i)
        break  # 找到就停止，不再继续
```

**输出：** `找到了，第一个是 3`

---

## ⏭️ continue —— 跳过本次

```python
# 打印1-10，但跳过所有偶数
for i in range(1, 11):
    if i % 2 == 0:  # 如果是偶数
        continue   # 跳过，不打印
    print(i)
```

**输出：** `1 3 5 7 9`

## 💡 实用例子

### 猜数字游戏（加强版）

```python
import random

答案 = random.randint(1, 100)
最多猜测次数 = 5

print("=== 猜数字游戏 ===")
print("我想了一个1-100的数字，你有5次机会！")

for 次数 in range(1, 最多猜测次数 + 1):
    猜测 = int(input(f"第{次数}次猜（还剩{最多猜测次数-次数+1}次）："))
    
    if 猜测 == 答案:
        print("🎉 恭喜你，猜对了！")
        break
    elif 猜测 < 答案:
        print("太小了，往大猜！")
    else:
        print("太大了，往小猜！")
else:  # 循环正常结束（没有被break）
    print("次数用完了！正确答案是", 答案)
```
