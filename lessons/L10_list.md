## 🏠 生活比喻：列表就像一个行李箱

想象你要收拾行李箱去旅行：

```
行李箱（列表）：
├── 位置0: 衣服
├── 位置1: 牙刷
├── 位置2: 手机
├── 位置3: 充电器
└── 位置4: 零食
```

列表就是这样一个**有序的容器**，每个位置放一个东西。

---

## 📝 创建列表

```python
# 空列表
购物清单 = []

# 有内容的列表
水果 = ["苹果", "香蕉", "橙子"]
数字 = [1, 2, 3, 4, 5]
混合 = ["小明", 18, 1.75, True]  # 可以混放不同类型

print(水果)    # ['苹果', '香蕉', '橙子']
print(数字)    # [1, 2, 3, 4, 5]
```

---

## 🔢 访问列表元素——用索引

```python
水果 = ["苹果", "香蕉", "橙子", "葡萄"]

print(水果[0])   # 苹果（第一个）
print(水果[1])   # 香蕉（第二个）
print(水果[-1])  # 葡萄（最后一个）
print(水果[-2])  # 橙子（倒数第二个）
```

**索引从0开始！**

```
列表:    ["苹果", "香蕉", "橙子", "葡萄"]
索引:      0       1       2       3
倒序:     -4      -3      -2      -1
```

---

## 🔄 切片——取一部分

```python
水果 = ["苹果", "香蕉", "橙子", "葡萄", "西瓜"]

print(水果[1:4])   # ['香蕉', '橙子', '葡萄']（位置1到3）
print(水果[:3])    # ['苹果', '香蕉', '橙子']（从头到2）
print(水果[2:])    # ['橙子', '葡萄', '西瓜']（从2到结尾）
print(水果[:])     # ['苹果', '香蕉', '橙子', '葡萄', '西瓜']（全部）
```

## ✏️ 修改列表元素

```python
水果 = ["苹果", "香蕉", "橙子"]

水果[0] = "草莓"        # 修改第一个
print(水果)             # ['草莓', '香蕉', '橙子']

水果[-1] = "葡萄"       # 修改最后一个
print(水果)             # ['草莓', '香蕉', '葡萄']
```

---

## ➕ 增加元素

```python
水果 = ["苹果", "香蕉"]

# 方法1：append() —— 在最后添加
水果.append("橙子")
print(水果)  # ['苹果', '香蕉', '橙子']

# 方法2：insert() —— 在指定位置插入
水果.insert(1, "葡萄")  # 在位置1插入
print(水果)  # ['苹果', '葡萄', '香蕉', '橙子']

# 方法3：extend() —— 合并另一个列表
更多水果 = ["西瓜", "哈密瓜"]
水果.extend(更多水果)
print(水果)  # ['苹果', '葡萄', '香蕉', '橙子', '西瓜', '哈密瓜']
```

---

## ❌ 删除元素

```python
水果 = ["苹果", "香蕉", "橙子", "葡萄"]

# 方法1：remove() —— 按值删除
水果.remove("香蕉")
print(水果)  # ['苹果', '橙子', '葡萄']

# 方法2：pop() —— 按位置删除（默认最后一个）
删除的 = 水果.pop()
print(删除的)   # 葡萄
print(水果)     # ['苹果', '橙子']

# 方法3：del —— 按位置删除
del 水果[0]
print(水果)  # ['橙子']

# 方法4：clear() —— 清空全部
水果.clear()
print(水果)  # []
```

---

## 🔍 查找元素

```python
水果 = ["苹果", "香蕉", "橙子"]

# in 检查是否存在
print("苹果" in 水果)   # True
print("西瓜" in 水果)   # False

# index() 找位置（找不到会报错）
位置 = 水果.index("香蕉")
print(位置)  # 1

# count() 统计出现次数
数字 = [1, 2, 3, 2, 4, 2]
print(数字.count(2))  # 3（2出现了3次）
```

---

## 📊 常用函数

```python
数字 = [3, 1, 4, 1, 5, 9, 2, 6]

print(len(数字))     # 8（长度）
print(max(数字))     # 9（最大值）
print(min(数字))     # 1（最小值）
print(sum(数字))     # 31（求和）

数字.sort()          # 排序（原地修改）
print(数字)          # [1, 1, 2, 3, 4, 5, 6, 9]

数字.reverse()       # 反转
print(数字)          # [9, 6, 5, 4, 3, 2, 1, 1]
```

---

## 🔄 遍历列表

```python
水果 = ["苹果", "香蕉", "橙子"]

# 方法1：普通for循环
for item in 水果:
    print(item)

# 方法2：带索引
for i in range(len(水果)):
    print(f"{i+1}. {水果[i]}")
```

## 💱 综合例子：待办事项

```python
待办事项 = []

while True:
    print("\n=== 麦叔待办清单 ===")
    print(f"当前有{len(待办事项)}个事项")
    
    for i, 事项 in enumerate(待办事项, 1):
        print(f"{i}. {事项}")
    
    print("\n1. 添加事项")
    print("2. 删除事项")
    print("3. 退出")
    
    choice = input("选择：")
    
    if choice == "1":
        事项 = input("输入事项：")
        待办事项.append(事项)
        print("添加成功！")
    elif choice == "2":
        编号 = int(input("删除第几个？")) - 1
        if 0 <= 编号 < len(待办事项):
            删除的 = 待办事项.pop(编号)
            print(f"已删除：{删除的}")
    elif choice == "3":
        print("再见！")
        break
```

## 📝 今日要点

```
✅ 列表 = 有序的容器，可以放很多东西
✅ 创建：[1, 2, 3] 或 list()
✅ 索引从0开始：列表[0]是第一个
✅ 切片：列表[开始:结束]
✅ 添加：append()/insert()/extend()
✅ 删除：remove()/pop()/del/clear()
✅ 查找：in / index() / count()
✅ 排序：sort() / reverse()
```
