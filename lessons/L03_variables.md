- 理解不同的数据类型

---

## 🏠 生活比喻：变量就像一个盒子

想象你有很多盒子。

每个盒子上贴一个**标签**（名字），里面可以放东西。

```
┌─────────────┐
│   盒子      │
│  标签：名字  │
│  里面：小明  │
└─────────────┘
```

**变量 = 贴了标签的盒子**
- 标签 = 变量名
- 盒子里的东西 = 变量的值

---

## 📝 变量的写法

```python
名字 = "小明"
```

| 部分 | 意思 |
|------|------|
| `名字` | 变量名（标签） |
| `=` | 赋值符号，把右边的值放进左边的变量 |
| `"小明"` | 变量的值（盒子里的东西） |

---

## 💻 完整例子

```python
# 定义变量
名字 = "小明"
年龄 = 18
身高 = 1.75

# 使用变量
print(名字)
print(年龄)
print(身高)
```

**输出：**
```
小明
18
1.75
```

## 🔤 变量命名规则

### ✅ 可以用的

| 变量名 | 可以吗？ | 原因 |
|--------|---------|------|
| `name` | ✅ | 英文单词 |
| `my_name` | ✅ | 用下划线连接 |
| `age1` | ✅ | 字母+数字 |
| `Name` | ✅ | 大小写不同是不同的变量 |
| `我的名字` | ✅ | 也可以用中文 |

### ❌ 不可以用的

| 变量名 | 为什么不行 |
|--------|-----------|
| `my-name` | 有减号，减号在Python里有特殊意思 |
| `1name` | 不能以数字开头 |
| `my name` | 中间有空格 |
| `print` | 这是Python的"关键字"，已经有特殊意思了 |

### 📋 麦叔的命名建议

```
✅ 变量名要见名知意
✅ 用英文或拼音，不要用奇怪的中文缩写
✅ 多个单词用下划线连接：user_name, total_count
✅ 常量（全大写）：MAX_SIZE, PI
```

## 🧱 变量可以放什么？—— 数据类型

变量就像不同的盒子，有的适合放衣服，有的适合放食物。

Python里主要有几种"盒子"（数据类型）：

### 1. 字符串（str）—— 放文字

```python
名字 = "小明"
爱好 = '编程'
自我介绍 = """
我叫小明，
我喜欢编程，
很高兴认识你。
"""
```

字符串用**引号**包起来，单引号或双引号都行。

### 2. 整数（int）—— 放整数

```python
年龄 = 18
人数 = 100
温度 = -10
```

### 3. 浮点数（float）—— 放小数

```python
身高 = 1.75
价格 = 19.9
体重 = 65.5
```

### 4. 布尔值（bool）—— 放对/错

```python
是学生 = True
有作业 = False
```

布尔值只有两个可能：`True`（真） 或 `False`（假）。

## 🔄 修改变量

变量可以随时修改：

```python
分数 = 60
print(分数)  # 输出：60

分数 = 80
print(分数)  # 输出：80
```

> 就像同一个盒子，先放苹果，再放香蕉——放进去什么，就是什么。

---

## 🔗 变量可以组合使用

```python
名字 = "小明"
print("我叫" + 名字)  # 输出：我叫小明

年龄 = 18
print(名字 + "今年" + str(年龄) + "岁")  # 输出：小明今年18岁
```

> 注意：文字和数字不能直接用 `+` 连接，需要用 `str()` 转一下。

## ❌ 常见错误

### 错误1：变量名没定义就用

```python
# ❌ 错误
print(名字)  # 名字还没定义

# ✅ 正确
名字 = "小明"
print(名字)
```

### 错误2：引号混用

```python
# ❌ 错误
信息 = "你好'

# ✅ 正确
信息 = "你好"
# 或
信息 = '你好'
```
