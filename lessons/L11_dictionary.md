## 🏠 生活比喻：字典就像真实的字典

想象一本中文字典：

```
"人" → 字典查"人"，得到解释：由类人猿进化而来的能制造工具并使用语言的高等动物
"好" → 字典查"好"，得到解释：优点多、令人满意
```

**键（Key）** → **值（Value）**

字典就是**键值对**的存储：知道键，就能找到值。

---

## 📝 创建字典

```python
# 空字典
学生 = {}

# 有数据的字典
学生 = {
    "姓名": "小明",
    "年龄": 18,
    "城市": "北京",
    "爱好": ["编程", "篮球", "音乐"]
}

print(学生)
```

---

## 🔍 访问字典——用键找值

```python
学生 = {
    "姓名": "小明",
    "年龄": 18,
    "城市": "北京"
}

print(学生["姓名"])  # 小明
print(学生["年龄"])  # 18
```

### 用 get() 安全访问

```python
# ❌ 如果键不存在，会报错
print(学生["体重"])  # KeyError！

# ✅ 用 get() 不存在返回 None 或默认值
print(学生.get("体重"))        # None
print(学生.get("体重", "未知"))  # 未知
```

---

## ✏️ 修改和添加

```python
学生 = {"姓名": "小明", "年龄": 18}

# 修改已有的键
学生["年龄"] = 19
print(学生)  # {'姓名': '小明', '年龄': 19}

# 添加新的键值对
学生["城市"] = "上海"
print(学生)  # {'姓名': '小明', '年龄': 19, '城市': '上海'}
```

---

## ❌ 删除

```python
学生 = {"姓名": "小明", "年龄": 18, "城市": "北京"}

# 方法1：del
del 学生["城市"]
print(学生)  # {'姓名': '小明', '年龄': 18}

# 方法2：pop() —— 删除并返回值
年龄 = 学生.pop("年龄")
print(年龄)   # 18
print(学生)   # {'姓名': '小明'}

# 方法3：clear() —— 清空
学生.clear()
print(学生)  # {}
```

## 🔄 遍历字典

### 遍历所有键

```python
学生 = {"姓名": "小明", "年龄": 18, "城市": "北京"}

for key in 学生.keys():
    print(key)
# 输出：姓名 年龄 城市
```

### 遍历所有值

```python
for value in 学生.values():
    print(value)
# 输出：小明 18 北京
```

### 遍历键值对

```python
for key, value in 学生.items():
    print(f"{key} = {value}")
# 输出：
# 姓名 = 小明
# 年龄 = 18
# 城市 = 北京
```

## 💱 实用例子：学生信息管理系统

```python
# 存储多个学生
学生们 = {
    "001": {"姓名": "小明", "年龄": 18, "分数": 92},
    "002": {"姓名": "小红", "年龄": 17, "分数": 88},
    "003": {"姓名": "小刚", "年龄": 19, "分数": 95},
}

# 查看某个学生
学号 = "002"
print(f"{学生们[学号]['姓名']}的分数是{学生们[学号]['分数']}")

# 给小红加分
学生们["002"]["分数"] = 90

# 新增一个学生
学生们["004"] = {"姓名": "小丽", "年龄": 18, "分数": 87}

# 打印所有学生
for 学号, 信息 in 学生们.items():
    print(f"{学号}: {信息['姓名']} - {信息['分数']}分")
```

```python
句子 = "apple banana apple orange banana apple"
单词列表 = 句子.split()
统计 = {}
for 单词 in 单词列表:
    if 单词 in 统计:
        统计[单词] = 统计[单词] + 1
    else:
        统计[单词] = 1
print(统计)
```
