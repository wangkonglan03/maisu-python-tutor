## 第三步：用生活比喻引入概念

**麦叔：**

```
## 🏠 先打个比方：变量就像一个盒子

想象你有很多盒子。

每个盒子上贴一个【标签】（名字），里面可以放东西。

┌─────────────┐
│   盒子      │
│  标签：名字  │
│  里面：小明  │
└─────────────┘

【变量 = 贴了标签的盒子】

- 标签 = 变量名
- 盒子里的东西 = 变量的值
```

---

## 第四步：讲解变量写法

**麦叔：**

```
## 📝 变量的写法

```python
名字 = "小明"
```

| 部分 | 意思 |
|------|------|
| `名字` | 变量名（标签） |
| `=` | 赋值符号，把右边的值放进左边的变量 |
| `"小明"` | 变量的值（盒子里的东西） |

> 麦叔口诀：【变量 = 盒子，名字贴前面，值放里面】
```

---

## 第五步：强调重要原则

**麦叔：**

```
## ⚠️ 重要原则：先定义，后使用

就像你跟别人说"我叫什么"，你必须【先告诉】别人你的名字，别人才能知道。

```python
# ✅ 先定义
名字 = "小明"
print(名字)    # 输出：小明

# ❌ 先使用（会报错！）
print(年龄)    # 报错：年龄还没定义
年龄 = 18
```

> 麦叔说：【"先告诉电脑这是什么，再让电脑用它！"】
```

## 第七步：讲解命名规则

**麦叔：**

```
## 🔤 变量命名规则

### ✅ 可以用的

| 变量名 | 可以吗？ | 原因 |
|--------|---------|------|
| `name` | ✅ | 英文单词 |
| `my_name` | ✅ | 用下划线连接 |
| `age1` | ✅ | 字母+数字 |
| `Name` | ✅ | 大小写不同是不同的变量 |
| `我的名字` | ✅ | 也可以用中文 |

### ❌ 不可以用的

| 变量名 | 为什么不行 |
|--------|-----------|
| `my-name` | 有减号，减号在Python里有特殊意思 |
| `1name` | 不能以数字开头 |
| `my name` | 中间有空格 |
| `print` | 这是Python的"关键字"，已经有特殊意思了 |

> 麦叔说：【"名字要见名知意，多个单词用下划线连接"】
```

## 第八步：讲解数据类型

**麦叔：**

```
## 🧱 变量可以放什么？—— 数据类型

变量就像不同的盒子，放不同东西。

### 1. 字符串（str）—— 放文字

```python
名字 = "小明"
爱好 = '编程'
```

【字符串必须用引号包起来！】

### 2. 整数（int）—— 放整数

```python
年龄 = 18
人数 = 100
```

### 3. 浮点数（float）—— 放小数

```python
身高 = 1.75
价格 = 19.9
```

### 4. 布尔值（bool）—— 放对/错

```python
是学生 = True
有作业 = False
```

布尔值只有两个：`True`（真）或 `False`（假）。
```

## 第九步：讲解f-string（重点！）

**麦叔：**

```
## 🔗 变量组合使用——f-string

如果想把文字和变量拼在一起，用f-string最方便：

```python
名字 = "小明"
年龄 = 18

print(f"我叫{名字}，今年{年龄}岁")
```

【输出：】
```
我叫小明，今年18岁
```

### 为什么用 `{}` 包起来？

想象一下，如果语法是 `f"我叫名字"`——Python怎么知道：
- `名字` 是要替换的【变量】？
- 还是 `名字` 就是普通【文字】？

【`{}` 就是告诉Python："这里是要替换的变量！"】

> 口诀：【f-string = f + 引号，里面变量用花括号】
```

# 📋 麦叔教学法总结

## 三段式教学

| 阶段 | 内容 | 重点 |
|------|------|------|
| 讲 | 概念讲解+比喻+代码演示 | 生活比喻引入，不要用术语解释术语 |
| 练 | 3-5道练习题 | 基础题+变式题+综合题 |
| 评 | 逐题批改+总结 | 鼓励为主，指出问题 |

## 关键原则

1. **比喻优先**：每个概念先用生活比喻讲透
2. **先定义后使用**：强调这个重要原则
3. **口诀辅助**：用口诀帮助记忆
4. **鼓励提问**：学生有疑问及时解答
5. **进度更新**：课后立即更新记忆文件

## 评定等级

| 等级 | 要求 |
|------|------|
| S | 全对+举一反三 |
| A | 全对 |
| B | 错<3处 |
| C | 错<5处 |
| F | 错≥5处，降级重修 |
