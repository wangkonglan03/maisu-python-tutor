# 麦叔Obsidian笔记系统 - 设置指南

## 📁 Obsidian文件夹结构

在新电脑上，把这个文件夹放到你的Obsidian vault里：

```
Python学习/
├── 00-总览.md           # 学习阶段总览、徽章墙
├── 01-课程进度.md        # 22课+5项目进度追踪表
├── 02-错题本.md         # 错题记录，遗忘≥5次触发降级
├── 03-待办事项.md        # 学习/复习/项目待办
├── 04-学习日记/          # 每日记录
│   ├── 2026-04-17.md    # 每日日记
│   └── 2026-04-20.md
├── 05-知识卡片.md        # 核心概念速查
└── 06-配置.md           # 麦叔配置方案
```

### 05-知识卡片.md
```markdown
# 知识卡片

## 变量相关

### 变量是什么
- 变量就像一个贴了标签的盒子
- 变量名 = 标签，变量值 = 盒子里东西

### 变量命名规则
- 可以：英文、数字、下划线、中文
- 不可以：减号，空格、数字开头

### 常用数据类型
- 字符串 str：文字，用引号包起来
- 整数 int：没有小数点的数字
- 浮点数 float：有小数点的数字
- 布尔值 bool：True 或 False

### 代码示例
```python
名字 = "小明"
年龄 = 18
print(f"我叫{名字}，今年{年龄}岁")
```

### 口诀
- print打印，括号包，内容用引号
- 先定义后使用

## 🔧 Obsidian设置

3. 选择包含 `Python学习/` 文件夹的目录

## 📝 上课时更新流程

每次上完课后，更新以下文件：

| 文件 | 更新内容 |
|------|---------|
| 01-课程进度 | 该课标记为✅，记录评定等级 |
| 02-错题本 | 如有错题，记录 |
| 03-待办事项 | 更新待办清单 |
| 04-学习日记/YYYY-MM-DD | 写今日日记 |
| 05-知识卡片 | 整理该课核心概念 |

---

## ⚠️ 重要：文件写入规则

Obsidian CLI对中文和代码处理有问题。

**规则：**
- 简单文字内容 → 可以用Obsidian CLI
- 复杂格式（代码块、表格）→ 用文件写入方式

**文件路径：**
```
C:\Users\【用户名】\【Obsidian vault路径】\Python学习\
```
