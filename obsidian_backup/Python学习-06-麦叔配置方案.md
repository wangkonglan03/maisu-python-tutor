## 四、教学教案参考方向

### 4.1 第一阶段：编程扫盲（L01-L08）

**目标：** 理解编程基本概念，能写简单程序

**教案参考方向：**
- 比喻教学：代码=菜谱、计算机=听话的员工
- 每课必须：生活比喻 → 代码演示 → 逐行解释 → 练习
- 练习难度：80%基础 + 15%变式 + 5%综合

### 4.2 第二阶段：循环与数据容器（L09-L16）

**目标：** 掌握程序流程控制和多种数据结构

**教案参考方向：**
- 循环：画程序流程图
- 列表：联系Excel表格理解
- 字典：联系真实字典的键值对
- 进阶：数据结构的互相转换

### 4.3 第三阶段：函数与模块（L17-L22）

**目标：** 能写出结构化、可复用的代码

**教案参考方向：**
- 函数：用"造工具"比喻，每个函数做一件明确的事
- 模块：用"工具箱"比喻，import就是借别人的工具
- 文件读写：用"笔记本"比喻，读=翻开、写=记录
- 错误处理：用"安全网"比喻，让程序不崩溃

### 4.4 第五阶段：方向深入

**AI方向参考路径：**
```
NumPy → Pandas → Matplotlib → Scikit-learn → PyTorch
教材：Kaggle入门课程、fast.ai课程
```

**前端方向参考路径：**
```
HTML/CSS基础 → JavaScript → Flask/FastAPI → REST API
教材：MDN Web Docs、FreeCodeCamp
```

**网络通讯方向参考路径：**
```
Socket编程 → HTTP协议 → 网络爬虫 → API调用
教材：Beej网络编程指南、Requests库文档
```

## 六、配置参数（详细版）

### 6.1 教学参数

| 参数 | 当前值 | 说明 |
|------|-------|------|
| 每节课建议时长 | 45分钟 | 讲10分钟+练25分钟+评10分钟 |
| 每课练习题数量 | 3-5道 | 基础题/变式题/综合题 |
| 评定总分 | 100分 | 100-60分不等 |
| 评定通过等级 | C级(60分) | C级以上才能进入下一课 |
| 补考次数上限 | 2次 | 超过2次触发降级 |
| 降级重修阈值 | 5次错误 | 同一知识出错5次触发 |

### 6.2 徽章积分规则

| 动作 | 获得积分 |
|------|---------|
| 完成一课 | +10分 |
| 完成一个项目 | +30分 |
| 评定S级 | +20分 |
| 评定A级 | +15分 |
| 评定B级 | +10分 |
| 评定C级 | +5分 |

**积分兑换：**
- 5积分 = 麦叔私人定制练习题
- 10积分 = 麦叔学习报告
- 20积分 = 麦叔认证毕业证书
